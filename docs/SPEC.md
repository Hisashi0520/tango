# 仕様書 (SPEC)

## 1. 目的

個人学習用の英単語フラッシュカードPWA。複数の単語帳に対応する。

## 2. 提供アプリ

### 2.1 flashcard-app.html（旧版・v1系・凍結中）

- 対象：旧版「必携英単語 LEAP」（2027語）
- 形式：スタンドアロン HTML PWA
- 特徴：単語のみ（例文なし）・4段階定着度・章別出題・全体統計
- 発音（v1.1.0〜）：Web Speech API（en-US・rate 0.9）で単語を読み上げ。表面（英→日モードのみ）と裏面にボタン。非対応端末では非表示。localStorage は変更なし

### 2.2 flashcard-leap.html（改訂版・v0.2.0〜／現行 v0.3.0）

- 対象：「改訂版 必携 英単語 LEAP」（竹岡広信著、数研出版、全2300語、2024年改訂）
- 形式：スタンドアロン HTML PWA（JSONデータをインライン埋め込み・file:// で起動可能）
- 特徴：
  - 単語＋品詞別意味の表示
  - 出題モード3択（X一括想起 / Y段階開示 / シンプル）
  - 4段階定着度（完璧／なんとなく／覚えてない／未学習）
  - 動的自己評価ボタン（意味総数に応じて構成変化）
  - 章別出題（4章機械分割）
  - 全体統計（章別＋総合）
  - ダークモード + ガラスモーフィズムデザイン
  - スワイプ・キーボードショートカット対応
  - 発音ボタン（v0.3.0〜）：Web Speech API（en-US）で単語を読み上げ。表面（英→日）に「発音」、裏面に「単語」。カードはめくれない。非対応端末では非表示

## 3. データ構造（leap-words.json）

```json
[
  {
    "no": 1,
    "word": "agree",
    "meanings": [
      { "pos": "自", "defs": ["賛成する", "（主語の中で）意見が一致する", "..."] }
    ]
  }
]
```

- `no`: 通し番号（1〜2300）
- `word`: 英単語
- `meanings`: 品詞ごとの意味ブロック配列
  - `pos`: 品詞（自/他/名/形/副/前/接 など）
  - `defs`: 意味の配列（①②③ で列挙されていた定義を分解したもの）

## 4. 章分割

LEAP本体の章境界情報は未取得のため、通し番号で機械的に4分割：

- 第1章：No.1〜575
- 第2章：No.576〜1150
- 第3章：No.1151〜1725
- 第4章：No.1726〜2300

将来、本体の章境界情報を入手したら差し替える（ADR.md 参照）。

## 5. 学習データ（localStorage）

- キー：`leap-revised-*` プレフィックス（旧版アプリのデータと衝突回避）
- 定着度：4段階（完璧／なんとなく／覚えてない／未学習）
- 永続化：ブラウザ localStorage（端末ローカルのみ・同期なし）

## 6. データソース

- 単語・意味：ukaru-eigo.com/leap-modified-list/ から取得（個人利用許諾、サイト明示）

- 著作権上、データJSONはGitHub等で公開しない（私的利用範囲に留める）

## 7. 出題モード

### 7.1 X: 一括想起モード（推奨・デフォルト）
- カード表面：英単語＋「··· N つの意味」ヒント
- ユーザーは頭の中で全意味を想起してからタップ
- カード裏面：全意味＋動的自己評価ボタン
- 用途：定期復習・実力テスト

### 7.2 Y: 段階開示モード
- カード表面：英単語のみ（ヒントなし）
- タップごとに ①→②→③ の順で意味が1つずつ開示
- 全意味開示後に自己評価
- 用途：新規単語の初回学習・じっくり覚えたい時

### 7.3 シンプルモード
- 既存（v0.1.x）の挙動を踏襲
- カード表面：英単語のみ
- カード裏面：全意味を一度に表示＋3段階評価
- 用途：軽く流したい時

### 7.4 動的自己評価ボタン

意味の総数（meanings配列内の全 defs の合計）に応じてボタン構成が変化する：

| 総意味数 | ボタン構成 | 内部評価マッピング |
|---|---|---|
| 1 | 完璧 / なんとなく / 覚えてない | 完璧 / なんとなく / 覚えてない |
| 2 | 2つとも / 1つ / 0つ | 完璧 / なんとなく / 覚えてない |
| 3 | 3つとも / 2つ / 1つ / 0つ | 完璧 / なんとなく / なんとなく / 覚えてない |
| 4以上 | ほぼ全部 / 半分以上 / 少し / 全然 | 完璧 / なんとなく / なんとなく / 覚えてない |

新ラベル「あやふや」（4段階表示時の3番目）は内部的には「なんとなく」として保存され、既存統計と完全互換。

## 8. flashcard-chugaku.html（中学英単語版・v1.0.0〜）

- 対象：中学英単語 1,812語（レベル1〜5）。形式は LEAP 版と同じスタンドアロン HTML PWA（JSON インライン埋め込み・file:// で起動可能）。
- 動作・デザイン（ダーク＋ガラス調、3Dカードめくり、英→日/日→英、出題スタイル X/Y/シンプル、4色自己評価、結果画面）は LEAP 版 v0.2.3 と同じ。

### 8.1 データ元
- 元データ：`c:/Dev/.pipeline/artifacts/eitango/level{1..5}_part*.tsv`（タブ区切り5列：単語／品詞／和訳／英語の例文／例文の和訳、ヘッダーなし、UTF-8）。レベル順 → part番号順 → 行順に読み、通し番号 `no` を 1 から付与。
- 変換：`scripts/build-chugaku-data.js` が `data/chugaku-words.json` を生成し、HTML の `<script id="chugaku-data" type="application/json">` へ埋め込む。件数（総数1,812・レベル別 360/362/365/378/347）を検証し、不一致なら異常終了。
- JSON 形式：`{no, word, level, meanings:[{pos, defs:[…]}], example, exampleJa}`。`defs` は和訳を「、」で分割。

### 8.2 範囲
| 選択肢 | 通し番号 | 語数 |
|---|---|---|
| レベル1（中1前半） | 1〜360 | 360 |
| レベル2（中1） | 361〜722 | 362 |
| レベル3（中2） | 723〜1087 | 365 |
| レベル4（中3） | 1088〜1465 | 378 |
| レベル5（発展） | 1466〜1812 | 347 |
| 全部 | 1〜1812 | 1,812 |

### 8.3 例文
- カード裏面の和訳の下に、例文（英）と例文の和訳を表示（英→日・日→英の両モード）。
- 英文中の見出し語は `<b>` で強調。語尾の e / y を除いた語幹の先頭一致（例: make→making）。活用で綴りが変わる語（take→took 等）は強調されない場合がある。
- Y モードでは全意味を開示するまで例文は透明（開示後に表示）。

### 8.4 発音
- Web Speech API の `speechSynthesis`（lang `en-US`、rate 0.9）で単語・例文を読み上げ。表面（英→日のみ）に「単語」ボタン、裏面に「単語」「例文」ボタン。
- ボタン操作はカードをめくらない（`stopPropagation`）。`speechSynthesis` が無い端末ではボタンを非表示。
- 音声は端末内蔵の音声に依存する（品質・利用可否は端末次第）。

### 8.5 localStorage キー
- `chugaku-tango-progress_v1`：学習進捗（`no` → 0/1/2）
- `chugaku-tango-quiz-mode`：出題スタイル（X/Y/simple）
- LEAP 版（`leap-revised-*`）とは衝突しない。

### 8.6 その他
- 版数は `APP_VERSION` とファイル冒頭コメント、設定画面の下に小さく表示。
- 元データの出典・利用範囲は私的利用の範囲に留め、データ JSON は公開しない方針（LEAP 版 6 章に準拠）。
