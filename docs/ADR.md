# Architecture Decision Record (ADR)

## ADR-001: データソースに ukaru-eigo.com の単語リストを採用（2026-05-14）

### 背景
LEAP改訂版2300語のフラッシュカードアプリを作るにあたり、単語＋意味のデータが必要。

### 検討した選択肢
1. 数研出版公式（chart.co.jp）：教員限定・一般非公開・DRM付き → 不可
2. 数研Library / StudyAid D.B.：有料アプリ・DRMで抽出不可 → 不可
3. mikan公式 LEAP：データ抽出機能なし・OSアプデで消失リスク → 不可
4. Anki / Quizlet 共有デッキ：断片的・DMCA削除リスク・改訂版未対応 → 不可
5. ukaru-eigo.com/leap-modified-list/：全2300語の単語＋意味・個人利用OK明示 → 採用
6. 紙の本→Gemini Vision OCR：純正例文まで取れるが撮影工数大 → 将来検討（ADR-003）

### 決定
ukaru-eigo.com の改訂版リストを採用。defuddle で markdown 化 → スクリプトで JSON 化。

### 結果
- 約2300語のデータを短時間で取得可能
- 例文は含まれない（部長判断で例文機能は不要と決定）
- 私的利用に留め、JSONデータはGitHub等で公開しない

## ADR-002: 例文機能は実装しない（2026-05-14）

### 背景
当初「LEAP本体の例文を問題として出したい」要望があったが、調査結果（NotebookLM ディープリサーチ）により以下が判明：
- LEAP本体例文はネット上に正規データ流通なし
- Anki共有デッキの「ランダム例文」はLEAP本体例文ではなく935語のみ
- 本体例文を取得する唯一の正規ルートは「自分で本を撮影してGemini VisionでOCR」

### 検討
- A案：Gemini Visionで本から例文抽出（純正・約$10・撮影2-4h）
- B案：Claude/Gemini で例文生成（CEFR準拠・著作権クリーン）
- 例文なし版：単語＋意味のみ

### 決定
部長判断により **例文機能は実装しない**（単語＋意味のみ）。

### 結果
- 既存 flashcard-app.html と同じシンプル設計を維持
- 将来的にA案で例文を後付けする余地は残す（データJSON構造に `examples` フィールドを追加するだけで対応可能）

## ADR-003: 章分割は通し番号での機械的4分割（2026-05-14）

### 背景
LEAP本体は意味グループ別に章立てされているが、ukaru-eigo.com のデータには章境界情報がない。

### 決定
通し番号で機械的に4分割（575語×3＋575語×1）。

### 結果
- 学習進捗の可視化は可能だが、テーマ別グルーピングは失われる
- 将来、本体の章境界情報を入手したら data/leap-words.json に `chapter` フィールドを追加して差し替え可能
